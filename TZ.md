ТЗ: приложение для тренировок
28 сент. 2026 г. · @Koxstantin
Задача
Собрать личное веб-приложение для силовых тренировок три раза в неделю: программа, отметка подходов прямо в зале, журнал и графики прогресса. Пользователь один — владелец, телефон iPhone, Safari, иконка на домашнем экране.
Сейчас работает прототип — один html-файл на 900 строк с программой, отметкой подходов, весом тела и двумя графиками. Его ограничения и есть причина переписывания:
• вся история хранится одним JSON в localStorage, истории рабочих весов по упражнениям нет — видно только последнее значение;
• нет истории выполненных подходов и повторов, поэтому прогресс по конкретному упражнению не посчитать;
• программа задана константой в коде, новый цикл на 8 недель заводится только правкой файла;
• нет офлайн-кеша: без сети страница не открывается;
• код в одном файле, тестов нет, добавлять функции рискованно.
Что должно получиться: устанавливаемое PWA, которое открывается за секунду, работает без сети в подвале зала, хранит всю историю тренировок и показывает, растут веса или стоят.
Стек и структура
Берём Vite + React + TypeScript, состояние в Zustand, хранение в IndexedDB через Dexie, графики рисуем сами на SVG без библиотек. Хостинг — GitHub Pages, деплой через GitHub Actions при пуше в main.

Модель данных
Главное отличие от прототипа: каждый выполненный подход пишется отдельной записью с весом и повторами. Из этого потом считается всё остальное.
Exercise {            // справочник упражнений
  id: string
  name: string
  muscle: 'chest'|'back'|'shoulders'|'biceps'|'triceps'|'legs'|'core'
  cue: string         // как делать, 1–3 предложения
  unit: 'kg'|'bodyweight'|'machine'
}

ProgramDay {          // день программы
  id: 'mon'|'wed'|'fri'
  name: string
  warmup: string
  items: ProgramItem[]
}

ProgramItem {
  exerciseId: string
  sets: number         // 4
  repsLow: number      // 6
  repsHigh: number     // 8
  restSec: number      // 150
  startWeight: number|null
  supersetWith?: string
}

Session {             // одна тренировка
  id: string
  date: string         // 2026-09-30
  dayId: 'mon'|'wed'|'fri'
  startedAt: number
  finishedAt: number|null
  note: string
}

SetEntry {            // один подход — ядро всей истории
  id: string
  sessionId: string
  exerciseId: string
  index: number        // номер подхода в упражнении
  weight: number|null  // кг, null для своего веса
  reps: number
  done: boolean
  at: number
}

BodyWeight { date: string, kg: number }
MaxTest    { date: string, kind: 'pullup'|'dip', reps: number }
Settings   { theme, units, cycleStart: string, weightTarget: number|null }
Правила хранения:
• таблицы Dexie: exercises, program, sessions, sets, bodyweight, maxes, settings;
• индексы: sets по sessionId и по паре exerciseId + at — по ним строятся графики;
• программа лежит в базе, а не в коде: сид загружается при первом запуске из seed.ts;
• версия схемы в Dexie, миграции через db.version(n).stores(...).upgrade();
• удаления нет, есть флаг deleted у упражнений программы, чтобы история не рвалась.
Экраны
Пять вкладок в нижней панели: План, Тренировка, График, Еда, Ещё. Открывается всегда на «Тренировке» с днём по текущей дате.
Тренировка
Основной экран, им пользуются с телефона в руке между подходами.
• Сегменты Пн / Ср / Пт, активный день подставляется по дню недели.
• Кнопка «Начать тренировку» создаёт Session; до этого экран в режиме просмотра.
• Карточка упражнения: название, схема подходов крупно, чипы отдыха и стартового веса, строка подходов.
• Строка подхода: кружок с номером, поле веса, поле повторов. Тап по кружку пишет SetEntry и запускает таймер отдыха.
• Вес и повторы подставляются из прошлой тренировки этого упражнения, менять можно двумя тапами (шаг ±2,5 кг и ±1 повтор).
• Таймер отдыха: круговой индикатор вверху экрана, вибрация по окончании, можно свернуть.
• Техника упражнения раскрывается по «Как делать».
• «Завершить тренировку» проставляет finishedAt, показывает сводку: тоннаж, время, число подходов.
План
• Восемь недель цикла с режимом каждой недели и отметками, сколько тренировок закрыто.
• Правила: запас повторов, шаг прибавки, отдых, работа с турником и брусьями — свёрнутые блоки.
• Редактор программы: добавить упражнение, изменить подходы и отдых, поменять порядок, выбрать упражнение из справочника.
График
Описан в следующем разделе.
Еда
Норма калорий и белка от текущего веса тела, пересчитывается автоматически. Поле целевого веса и оценка, за сколько недель он наберётся при текущем темпе.
Ещё
Тема (авто, светлая, тёмная), экспорт и импорт JSON, очистка истории, версия приложения, ссылка на установку иконки.

Графики на вкладке «График»:
1. Вес тела — линия за выбранный период, 4 недели или 6 месяцев, с заливкой под кривой.
2. Тренировки по неделям — столбцы за 8 недель, три из трёх подсвечены зелёным.
3. Прогресс по упражнению — выбираешь упражнение из списка, видишь линию оценочного максимума и точки фактических подходов за всё время.
4. Тоннаж по неделям — столбцы, чтобы видеть, растёт объём или падает.
Подсказка прибавки веса. После завершения тренировки приложение проверяет каждое упражнение по правилу двойной прогрессии: если во всех подходах достигнут верх диапазона повторов, показывает «в следующий раз +2,5 кг» для штанги и блока, «+1 кг на гантель» для гантелей. Прибавку не применяем сами, только предлагаем; пользователь принимает одним тапом, и startWeight в программе обновляется.

Требования интерфейса:
• любая цель нажатия не меньше 44×44 пунктов — в зале руки потные и трясутся;
• всё управление тренировкой в нижней половине экрана, достаётся большим пальцем;
• цифры набором с табличными цифрами (font-variant-numeric: tabular-nums), чтобы не прыгали;
• панели и сегменты через backdrop-filter: blur(24px) saturate(180%), карточки — полупрозрачные с тонкой рамкой;
• отступы от вырезов через env(safe-area-inset-*);
• анимации только в ответ на действие: плашка сегмента едет, подход пружинит при отметке, таймер отдыха обводится по кругу; длительность 200–320 мс, кривая cubic-bezier(.32,.72,0,1);
• prefers-reduced-motion выключает всю анимацию;
• контраст текста не ниже 4,5:1, фокус виден с клавиатуры.
Офлайн и установка
Приложение должно открываться и работать полностью без сети: в зале связи может не быть.
• Манифест: name «Зал», short_name «Зал», display: standalone, theme_color: #0E1216, иконки 180, 192 и 512 пикселей.
• Service worker через vite-plugin-pwa в режиме autoUpdate: весь бандл в precache, стратегия cache-first.
• Новая версия ставится молча, при следующем открытии показывается плашка «Обновлено».
• Все данные локальные, сеть для работы не нужна вообще.
• Экспорт: кнопка сохраняет файл zal-backup-ГГГГ-ММ-ДД.json со всей базой. Импорт принимает такой файл и заменяет базу после подтверждения.
• Автоматическое напоминание о резервной копии раз в месяц, если экспорта давно не было.
Синхронизация между устройствами в первую версию не входит. Если понадобится, добавляем позже: экспорт в приватный gist или в облако через токен в настройках. Отдельный сервер не поднимаем.

Обязательные проверки:
[ ] Отметка подхода не теряется при закрытии приложения посреди тренировки
[ ] Миграция схемы не стирает историю
[ ] Импорт чужого или битого JSON не ломает базу, показывает ошибку
[ ] Всё работает одной рукой, ничего важного выше середины экрана
[ ] Данные прототипа переносятся: скрипт превращает старый JSON в новую схему
Что в первую версию не входит: синхронизация между устройствами, аккаунты, дневник питания с подсчётом продуктов, видео техники, экспорт в PDF.
